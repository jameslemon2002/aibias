# Release Scope

This public package covers the current manuscript's main-text and supplementary figure materials.

## Included analytical scope

- open-perception main figures through released source tables
- structured-perception main figures through released source tables
- supplementary prompt and robustness materials
- curated supplement figure regeneration

## Not included

- raw API-driven generation workflows
- provider-specific street-view download pipelines
- manuscript writing files
- private local environment configuration

## Rationale

The full working tree mixes reproducible figure assets with provider-specific collection logic,
private runtime settings, and exploratory code. This release isolates the portion that is
appropriate for long-term public maintenance and manuscript review.
